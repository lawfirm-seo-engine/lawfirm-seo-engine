## 1. 벨라비 사기 쇼핑몰 사칭 피해 개요

벨라비 사기 쇼핑몰 사칭은 쇼핑몰·팀미션 사칭 피해 신고가 접수된 사례입니다. 쇼핑몰 구매 대행, 리뷰 미션, 팀미션 주문 처리 방식 방식으로 피해자에게 접근하며, 상품 주문 처리나 리뷰 미션 수행을 요청한 뒤 주문 금액, 정산 포인트, 등급 업그레이드비, 주문 오류 해결비 명목으로 금전을 요구합니다. 피해 발생 후에는 정산 지연·환불 거부를 이유로 추가 입금을 반복 요구하는 패턴이 확인됩니다.

## 2. 벨라비 사기 쇼핑몰 사칭 접근 방식

쇼핑몰·팀미션 사기는 쇼핑몰 구매 대행, 리뷰 미션, 팀미션 주문 처리 방식 방식을 통해 피해자를 끌어들입니다. 피해자는 처음에 상품 주문 처리나 리뷰 미션 수행을 요청받고, 신뢰가 쌓인 뒤 점차 주문 금액, 정산 포인트, 등급 업그레이드비, 주문 오류 해결비 명목으로 금전을 요구받습니다.

처음에는 소액으로 시작해 실제로 수익이 발생하는 것처럼 보이도록 유도하며, 출금이나 환불을 요청하면 정산 지연·환불 거부을 이유로 추가 입금을 요구하는 구조가 반복됩니다.

## 3. 벨라비 사기 쇼핑몰 사칭 피해 사례

**사례 1** — 쇼핑몰 구매 대행 업무처럼 안내받고 소액 주문을 처리했다가, 주문 금액이 점차 커지면서 정산이 지연되는 유형입니다. 출금 요청 시 계정 오류나 보증금을 이유로 추가 입금을 요구합니다.

**사례 2** — 팀미션 주문을 완료하면 수수료를 지급한다고 안내받고 참여했다가, 등급 업그레이드 비용이나 오류 해결비 명목으로 반복 요금을 청구받은 유형입니다.

**사례 3** — 정상 쇼핑몰처럼 보이는 사이트에서 리뷰 미션을 수행했지만, 포인트 환전이나 출금 단계에서 세금 또는 수수료를 요구받고 연락이 끊기는 유형입니다.

## 5. 벨라비 사기 쇼핑몰 사칭 대응 절차

벨라비 사기 쇼핑몰 사칭 피해는 초기 대응 속도가 피해 회복률에 직접적인 영향을 미칩니다. 아래 순서에 따라 즉시 행동하시기 바랍니다.

**① 증거 확보 (최우선)**

상대방과의 대화창이 삭제되거나 계정이 차단되면 복구가 어렵습니다. 지금 바로 아래 자료를 캡처·저장하세요.

- 상대방이 보낸 수익 화면, 계약서, 안내문
- 상대방 연락처·계좌번호·플랫폼 URL

**② 추가 입금 즉시 중단**
